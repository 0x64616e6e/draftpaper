# Security

Draftpaper draws the lock screen and the login screen, and starts programs again after a login, so a
flaw in it can matter. If you find one, please report it privately: on GitHub, **Security → Report a
vulnerability** on this repository. Please don't open a public issue for it.

Say what an attacker can do and how, and on which version (`draftpaper version`). A fix is released
as soon as it is ready, and the report is credited in the CHANGELOG unless you'd rather not be.

Only the latest release is supported.
